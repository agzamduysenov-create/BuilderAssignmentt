# Builder Assignment - Tea Ordering System

Учебный проект по паттерну проектирования **Builder (Строитель)** на Java (JDK 17) [cite: 1].

## Что за проект
Программа пошагово собирает заказы чая (Bubble Tea и Зеленый чай) с помощью шаблона Строитель [cite: 1].

## Структура проекта
* `Tea.java` — сам объект чая (продукт) [cite: 1]
* `TeaBuilder.java` — интерфейс строителя [cite: 1]
* `BubbleTeaBuilder.java` — собирает бабл-ти [cite: 1]
* `GreenTeaBuilder.java` — собирает зеленый чай [cite: 1]
* `TeaDirector.java` — директор для стандартных рецептов [cite: 1]
* `Main.java` — запуск программы [cite: 1]

## Как запустить
1. Открой проект в IntelliJ IDEA [cite: 1].
2. Запусти файл `Main.java` [cite: 1].
