# Builder Assignment — Tea Ordering System

Учебный проект на Java (JDK 17) по паттерну проектирования **Builder (Строитель)**. Программа пошагово собирает заказы чая (Bubble Tea и Зеленый чай).

## Структура проекта
* `Tea.java` — сам объект чая (продукт)
* `TeaBuilder.java` — интерфейс строителя
* `BubbleTeaBuilder.java` — собирает бабл-ти
* `GreenTeaBuilder.java` — собирает зеленый чай
* `TeaDirector.java` — директор для стандартных рецептов
* `Main.java` — запуск программы
